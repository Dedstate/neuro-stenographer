# Изменения

## Подготовка main

- Объединены ASR, диаризация и интеграционное приложение.
- Основной Android-проект находится в android/, ранние проекты сохранены в experiments/.
- Корневой Gradle wrapper запускает основное приложение.
- Добавлены инструкции сборки для Linux/Fedora, сценарий показа и сводка проверок.
- README оформлен с баннером, навигацией, моделями и описанием результата.

## 0.1.2

Исправлен JNI-callback прогресса диаризации для Kotlin 2. Добавлены проверка сигнатуры в JVM и конечном DEX. [Подробности](docs/releases/0.1.2.md).

## 0.1.1

Устранён конфликт ELF-версий ONNX Runtime и Sherpa JNI. Java JNI-мост пересобран под комплектный runtime Sherpa.

## 0.1.0

Подготовлен единый Android-конвейер: импорт, декодирование, диаризация, GigaAM, RUPunct, отображение и экспорт JSON. Все модели включаются в APK.
