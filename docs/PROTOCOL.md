# JSON

UTF-8, объект с единственным полем `transcript`. Реплики сортируются по началу; пересечения допустимы при одновременной речи.

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

`speaker_id` - непустая строка; `start_ms`/`end_ms` - целые миллисекунды относительно начала импортированного аудио, `0 <= start_ms < end_ms`; `text` - строка. Идентификаторы стабильны внутри одного результата и нормализуются по первому появлению. Между разными записями идентичность человека не устанавливается. Тишина может дать `{"transcript":[]}` с предупреждением в интерфейсе. Ошибка модели не подменяется фиктивным текстом.

Проверка схемы: `python3 scripts/evaluate.py transcript.json`.
