# Ограничения

- Не подтверждены Android-инференс данной сборки, пик памяти/RTF на устройстве с 4 ГБ и качество на конкурсных записях.
- Кластеризация может склеивать разные голоса или дробить один. Количество участников автоматическое, не задано как 2.
- Наложения не разделяются на источники. Пересекающиеся интервалы сохраняются, UI предупреждает о возможном повторении текста.
- Таймкоды относятся к интервалам диаризации/ASR-фрагментам, не являются forced alignment отдельных слов.
- До 10 минут и 512 МБ на вход. Для более длинных записей потребуется другой план памяти/обработки.
- WAV PCM16/24/32 и float32; WAVE_FORMAT_EXTENSIBLE, 8-bit и RF64 не поддержаны. Сжатые контейнеры зависят от MediaCodec Android.
- RUPunct применяется только к строкам из русских/латинских букв и цифр, разделённых пробелами. При исходной пунктуации/спецсимволах возвращается исходный текст; при ошибке модели показывается предупреждение.
- RUPunct не генерирует резюме встречи. «Локальная языковая модель» здесь — специализированный токен-классификатор, не чат-модель.
- Сервис фоновой обработки, запись с микрофона, редактирование и воспроизведение по таймкодам отсутствуют.
- Debug APK предназначен для sideload-проверки. Release signing/Play Store публикация не настраивались.
