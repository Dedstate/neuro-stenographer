# 0.1.2

## Изменения

- Исправлен native crash в callback прогресса диаризации при Kotlin 2.
- Добавлен именованный DiarizationProgressCallback с типизированным invoke.
- Сигнатура callback проверяется JVM-тестом и в готовом DEX.
- Android smoke-тест использует processWithCallback, как основной конвейер.
- Этап загрузки моделей диаризации отделён от этапа определения говорящих в статусе приложения.

## Сохранено из 0.1.1

- Комплектный ONNX Runtime Sherpa 1.28.2.
- Java JNI bridge, пересобранный под точные ELF-версии runtime.
- Проверка моделей и нативных библиотек в APK.

## Проверки

15 JVM-тестов, 6 Python-тестов, сборка приложения и instrumentation APK, lint без ошибок, проверка модели/ABI/ELF/DEX и подписи APK. Полная оценка качества и производительности на целевом устройстве выполняется отдельно.
