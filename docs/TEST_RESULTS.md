## Пользовательский тест, 5 минут

Получен JSON после обработки фрагмента русскоязычной постановки «Предложение» А. П. Чехова. Вход: WAV PCM16, mono, 16 kHz, длительность 300 с. Проверка схемы экспорта пройдена.

| Показатель | Значение |
|---|---:|
| Речевых фрагментов | 68 |
| Разных speaker_id | 15 |
| Первое начало | 31 мс |
| Последнее окончание | 299967 мс |
| Фрагментов короче секунды | 12 |
| Пар пересекающихся фрагментов | 3 |

Результат подтверждает прохождение пользовательского сценария до экспорта. В JSON нет номера версии APK, времени обработки и характеристик устройства, поэтому эти показатели не приписываются конкретной сборке или телефону.

### Наблюдения

- Содержание диалога распознаётся, но встречаются ошибки слов и обрывы коротких фрагментов.
- Один монолог разделён между speaker_2, speaker_1 и speaker_10. Это ошибочное дробление одного голоса.
- В некоторых кластерах смешаны реплики разных персонажей.
- Пунктуация применяется, но границы предложений и регистр местами неверны.
- Для WER и DER нужна проверенная эталонная разметка. Проценты точности пока не приводятся.

Обезличенные числовые показатели сохранены в [five-minute-summary.json](../artifacts/test-results/five-minute-summary.json). Пользовательские логи и полная стенограмма в репозиторий не добавляются.

## Исправленные интеграционные сбои

| Версия | Причина | Исправление |
|---|---|---|
| 0.1.1 | Sherpa требовала ELF-символ ORT VERS_1.28.2, Maven runtime экспортировал VERS_1.28.0 | Комплектный runtime Sherpa и пересобранный Java JNI bridge; проверка версий символов |
| 0.1.2 | Kotlin 2 indy-lambda не содержала типизированного invoke, ожидаемого Sherpa JNI | Именованный callback, JVM-тест точного дескриптора и проверка DEX |

APK 0.1.0 отвергается проверкой ELF, APK 0.1.1 отвергается проверкой callback. Это регрессионные проверки, а не обещание отсутствия других ошибок.

## Следующие измерения

Пока не получены подтверждённые WER/DER, RTF и пик памяти на устройстве с 4 ГБ. Для каждого прогона фиксируются устройство, Android, ABI, длительность входа, холодный/тёплый запуск, время, максимальный наблюдаемый PSS и результат экспорта. Порядок проверки описан в [RELEASE_PLAN.md](RELEASE_PLAN.md).
