# Результаты

- `apk-build.json`: версия, размер и SHA-256 проверенного APK.
- `five-minute-summary.json`: числовые показатели пользовательского экспорта длительностью 5 минут.
- `results.csv`: таблица прогонов. Неизмеренные значения оставлены пустыми.

Сводный отчёт: [docs/TEST_RESULTS.md](../../docs/TEST_RESULTS.md). Точность ASR и диаризации не оценивается по одному факту успешного экспорта.
