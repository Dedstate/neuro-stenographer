# Прототипы

Здесь сохранены ранние разработки из объединённых веток. Основное приложение собирается из `android/` в корне репозитория.

| Папка | Происхождение | Содержимое |
|---|---|---|
| asr-qwen | feature/asr-llm | Первые адаптеры GigaAM и Qwen, экспериментальный AAR |
| diarization-adapter | feature/diarization | Адаптер диаризации, baseline APK/модель, исходный отчёт |
| diarization-standalone | прежний main | Самостоятельный Android-проект эксперимента с диаризацией |

Qwen и библиотеки этих проектов не подключены к основному приложению. Текущая пунктуация работает через RUPunct. Старые результаты относятся к соответствующим прототипам и не являются метриками основной сборки.
